# Hamnama Stream

نسخه دوم «باهم ببینیم» با سیستم Host / Guest.

## امکانات

- نفر اول روم = Host
- نفر دوم روم = Guest
- فقط Host ویدئو را انتخاب می‌کند
- Guest به صورت خودکار همان ویدئو را دریافت می‌کند
- پشتیبانی از فایل ویدئویی
- پشتیبانی از لینک HTTP/HTTPS
- پشتیبانی از HLS با لینک m3u8
- Play / Pause همگام
- Seek همگام
- نوار زمان
- چت دو نفره
- Fullscreen
- حالت افقی
- اگر Host خارج شود، Guest تبدیل به Host می‌شود
